# Glossário

| Termo | Significado |
|---|---|
| **Agendamento** | Um atendimento técnico marcado para uma data e hora |
| **Ausência** | Período em que o técnico não atende (férias, licença, curso etc.) |
| **CAP** | Coordenadoria que confere as solicitações do portal cujo processo não foi localizado automaticamente |
| **Caixa organizadora** | Conta de e-mail institucional que envia os convites das reuniões do Teams |
| **Chamado** | Pedido de orientação de pré-projeto, com troca de mensagens entre o munícipe e a equipe |
| **Comunique-se** | Exigência feita no processo, que o interessado precisa atender |
| **Coordenadoria** | Unidade da SMUL que reúne várias divisões |
| **Despacho de indeferimento** | Decisão que negou o pedido do processo; pode gerar recurso |
| **Divisão** | Unidade dentro de uma coordenadoria, onde os servidores estão lotados |
| **Faixa de agenda** | Horário fixo e recorrente em que o técnico atende (ex.: toda terça, das 9h às 11h, online, 30 min por atendimento) |
| **Modalidade** | Presencial ou online (pelo Microsoft Teams) |
| **Munícipe** | Cidadão ou profissional que solicita o atendimento |
| **Ocorrência** | Um comunique-se ou despacho encontrado para o processo informado |
| **Ponto focal** | Servidor que organiza os atendimentos da sua divisão/coordenadoria |
| **Processo digital** | Número no formato `0000.0000/0000000-0` |
| **Processo físico** | Qualquer outro formato de número de processo |
| **Protocolo** | Número que identifica uma solicitação (no BI ou nos pedidos de pré-projeto) |
| **RF** | Registro funcional do servidor |
| **Sala Arthur Saboya** | Serviço de orientação técnica sobre pré-projetos |
| **Técnico reserva** | Técnico que atende no lugar do responsável original quando este está ausente |

## Situações (status) do agendamento

| Situação | O que significa |
|---|---|
| Solicitado | Pedido recebido, aguardando confirmação |
| Agendado | Confirmado. Data e hora garantidas |
| Atendido | O atendimento aconteceu |
| Concluído | Atendimento encerrado |
| Não realizado | O atendimento não aconteceu (ex.: ausência do munícipe) |
| Cancelado | Cancelado pelo munícipe ou pela SMUL |
