# Portaria

Você usa o sistema para **receber os munícipes** dos atendimentos presenciais.

1. Entre com o seu login e senha de rede. Se a sua conta usa uma senha própria do sistema, use a senha fornecida pela equipe de sistemas (**Pendente de confirmação**: nenhuma tela cadastra essa senha; ela é definida diretamente no banco).
2. A página inicial mostra os **agendamentos do dia**, com horário, munícipe, processo, técnico e situação.
3. Use a busca para achar o munícipe pelo nome, processo ou CPF.
4. Abra o agendamento para ver o local, a sala e as orientações de acesso e encaminhar o munícipe.

A portaria só consulta. Não altera nem cancela agendamentos. Se o munícipe não estiver na lista, peça que confira o agendamento no portal ou procure o ponto focal da área.
